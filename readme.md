
# Watchtower

A passive network traffic analyzer written in Python. It sniffs DNS and TLS SNI traffic, extracts domain names, tracks device bandwidth, and flags suspicious trackers.

> **Note:** Because modern network switches (and Wi-Fi routers) isolate traffic, this tool only monitors traffic generated by the machine it is running on. To monitor the whole network, it must be integrated with a DNS sinkhole (like Pi-hole) or run directly on a router.

## Requirements
- Python 3
- `scapy` (`sudo apt install python3-scapy`)

## Usage
Because Watchtower sniffs raw network traffic, it must be run with `sudo`:

```bash
sudo python3 watchtower.py
```

Then open **http://localhost:8081** in your browser.

## Features
- **Live Dashboard:** Updates every 2 seconds.
- **SNI Extraction:** Sees domain names even inside HTTPS traffic.
- **Bandwidth Tracking:** Shows exactly how much data this specific device is uploading and downloading.
- **Tracker Alerts:** Flags known ad and tracking domains.
